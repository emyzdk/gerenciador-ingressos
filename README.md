# 🎟️ Gerenciador de Ingressos

## 🧩 Sobre o Projeto
O "Gerenciador de Ingressos" é uma aplicação front-end desenvolvida para simular a lógica de venda e reserva de ingressos para eventos (como shows, cinema ou teatro). Criado como parte dos exercícios propostos nos cursos de desenvolvimento web da Alura, foca na integração fluida entre as tecnologias front-end. O objetivo principal é praticar a manipulação do DOM e a lógica de gestão de estoque/vagas utilizando JavaScript, permitindo ao usuário selecionar a quantidade de ingressos, verificar a disponibilidade em tempo real e visualizar o custo total dinamicamente.
